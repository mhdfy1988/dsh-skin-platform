# dsh-skin-runtime

DeepSeek Harness Web 皮肤平台的共享运行时。它提供皮肤注册表、外观设置页、Host 持久化、主题 token 桥接、全局装饰层、统一静态资源路由和用户自选背景。

每个 `SkinPack` 必须声明 `fixed-light`、`fixed-dark` 或 `adaptive`。固定模式把选定分支作为模式无关覆盖层提交给官方主题服务，不修改官方外观设置；停用皮肤后覆盖层被释放，官方选择立即恢复。

运行时只通过官方主题令牌和稳定的 `data-slot` 标记处理宿主表面，不依赖构建生成的 CSS 类名。

本包必须作为配置档案的直接插件安装；单个皮肤包的 peer 依赖不会自动激活本运行时。

## 用户自选背景

- 入口：“设置 → 皮肤 → 我的背景”；
- 支持 PNG、JPEG、WebP、GIF、AVIF，默认上限 25 MiB；
- 图片固定保存在 `<DSH_HOME>/skin-runtime/user-background`，不会写入 `settings.yaml` 或任何皮肤包；
- 设置只保存内容版本、显示开关、填充方式、位置、透明度、模糊和遮罩；
- 自定义图片只替换背景图层，当前皮肤的主题 token、字体和装饰层继续生效；
- 关闭“显示背景”会保留本地文件，点击“移除”才会清空设置并删除该副本。

Host 根据图片字节签名判断格式，并限制请求大小；浏览器写入要求同源。SVG 不进入用户背景链路。
